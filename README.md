# 关西旅行随身攻略(2027中秋)

手机网页版旅行攻略:大阪·京都·奈良 9天8晚(2027.9.10-9.19),姐弟2人自由行。

## 功能

- 📅 每日行程时间轴,Day 0-D9 切换
- 🎫 行程里直接显示景点门票价格(日元≈人民币),预算页有门票明细总表
- 📖 点行程里带📖的名字,弹出景点介绍(门票/开放时间/贴士)
- 🍜 美食清单标签页:20+餐厅小吃,点开看招牌菜、参考价、两人分工
- 🗺️ 每个地点一键唤起 Google Maps / 苹果地图导航
- ✅ 行李清单打勾,浏览器本地自动保存
- 💴 日元⇄人民币实时换算
- 🆘 应急电话一键拨打、常用日语一键复制

## 使用

- 在线:访问 GitHub Pages 地址(手机浏览器打开即可)
- 本地:直接双击 `index.html`

数据更新后重新部署即可。文字版完整攻略见同目录上级的 `2027中秋日本关西攻略.md` / `.pdf`。
